# 박범현

Java와 Spring Boot를 중심으로 업무 시스템을 개발하는 백엔드 웹개발자입니다.

요구사항을 API와 데이터 모델로 구체화하고, 실제로 동작하며 검증할 수 있는 서비스로 구현하는 과정에 집중합니다.

## 경력

SI 환경에서 업무 시스템 개발과 운영을 경험한 백엔드 웹개발자

## 주요 기술

### Backend

* Java
* Spring Boot
* MyBatis

### Database

* PostgreSQL
* MariaDB

### Frontend

* React
* TypeScript

### Infrastructure

* Docker
* Linux
* GitHub Actions
